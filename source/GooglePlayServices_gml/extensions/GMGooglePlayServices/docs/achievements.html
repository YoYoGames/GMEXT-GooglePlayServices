play_services_achievements_show

Shows the system Achievements UI overlay, listing every achievement for this game.


Syntax:

play_services_achievements_show()


Returns:

PlayServicesError

PlayServicesError.Ok if the UI was launched, PlayServicesError.NotAuthenticated or PlayServicesError.ActivityNull otherwise.

play_services_achievements_increment

Increments an incremental achievement's progress by a number of steps. Has no effect beyond unlocking the achievement once total_steps is reached - calling it again afterward is harmless. Use play_services_achievements_set_steps instead if you want to set an absolute step count rather than add to it.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_services_achievements_increment(achievement_id, steps, callback)
Argument Type Description
achievement_id String The unique ID of the (incremental) achievement.
steps Real The number of steps to add.
callback Function The function to call once the request completes.


Returns:

PlayServicesError

PlayServicesError.Ok if the request was accepted, PlayServicesError.NotAuthenticated or PlayServicesError.ActivityNull otherwise.


Triggers:

Callback

Fires once, when the request completes or fails.

Key Type Description
status PlayServicesResult The request's outcome.

play_services_achievements_unlock

Unlocks (PlayServicesAchievementState.Unlocked) the given achievement for the signed-in player. For an incremental achievement, this immediately completes it regardless of its current step count.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_services_achievements_unlock(achievement_id, callback)
Argument Type Description
achievement_id String The unique ID of the achievement.
callback Function The function to call once the request completes.


Returns:

PlayServicesError

PlayServicesError.Ok if the request was accepted, PlayServicesError.NotAuthenticated or PlayServicesError.ActivityNull otherwise.


Triggers:

Callback

Fires once, when the request completes or fails.

Key Type Description
status PlayServicesResult The request's outcome.


Example:

play_services_achievements_unlock("CgkI....", function(_status)
{
    if (_status.success)
        show_debug_message("Achievement unlocked");
});

play_services_achievements_get_status

Loads the current state of every achievement for this game, for the signed-in player.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_services_achievements_get_status(force_reload, callback)
Argument Type Description
force_reload Boolean If true, bypasses the local cache and fetches fresh data from the
server.
callback Function The function to call once the load completes.


Returns:

PlayServicesError

PlayServicesError.Ok if the request was accepted, PlayServicesError.NotAuthenticated or PlayServicesError.ActivityNull otherwise.


Triggers:

Callback

Fires once, when the load completes or fails.

Key Type Description
status PlayServicesResult The load's outcome.
achievements Array of PlayServicesAchievement Every achievement's current state.
Empty on failure.


Example:

play_services_achievements_get_status(false, function(_status, _achievements)
{
    if (!_status.success) return;

    for (var i = 0; i < array_length(_achievements); i++)
    {
        var _achievement = _achievements[i];
        show_debug_message($"{_achievement.name}: {_achievement.state}");
    }
});

PlayServicesAchievementState

An achievement's unlock state.

These constants are referenced by the following structs:

  • PlayServicesAchievement


Member Description
Unlocked The achievement has been unlocked.
Revealed The achievement is visible to the player but not yet unlocked.
Hidden The achievement's existence is not yet shown to the player.

PlayServicesAchievementType

Whether an achievement unlocks all at once or tracks incremental progress.

These constants are referenced by the following structs:

  • PlayServicesAchievement


Member Description
Standard Unlocked in a single step - play_services_achievements_unlock only.
Incremental Tracks progress via current_steps/total_steps -
play_services_achievements_increment/play_services_achievements_set_steps
apply.

PlayServicesAchievement

An achievement's current state for the signed-in player. current_steps/total_steps are only meaningful for PlayServicesAchievementType.Incremental achievements - both are 0 for a Standard achievement.

This struct is referenced by the following functions:

  • play_services_achievements_get_status


Member Type Description
achievement_id String The achievement's unique ID.
name String The achievement's display name.
description String The achievement's description (typically the "how to unlock" text).
state PlayServicesAchievementState The achievement's current state.
type PlayServicesAchievementType Whether this achievement is standard or
incremental.
current_steps Real The number of steps completed so far. Incremental achievements only.
total_steps Real The total number of steps required to unlock. Incremental achievements
only.
last_updated_timestamp Real When this achievement was last updated, in milliseconds since
epoch.
xp_value Real The XP awarded for unlocking this achievement.
revealed_image_uri String A URI for the achievement's revealed-state image. Convert to
a local path with play_services_uri_to_path before loading it as a sprite. Only present
once the achievement has been revealed.
unlocked_image_uri String A URI for the achievement's unlocked-state image. Convert to
a local path with play_services_uri_to_path before loading it as a sprite. Only present
once the achievement has been unlocked.

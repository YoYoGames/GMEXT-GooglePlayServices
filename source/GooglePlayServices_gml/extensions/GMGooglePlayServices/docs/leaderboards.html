play_services_leaderboard_show_all

Shows the system Leaderboards UI overlay, listing every leaderboard for this game.


Syntax:

play_services_leaderboard_show_all()


Returns:

PlayServicesError

PlayServicesError.Ok if the UI was launched, PlayServicesError.NotAuthenticated or PlayServicesError.ActivityNull otherwise.

play_services_leaderboard_submit_score

Submits a score to a leaderboard, evaluated against the daily/weekly/all-time buckets simultaneously. Only the highest score per bucket is ever kept - submitting a lower score than the player's existing best for a bucket has no effect on that bucket. Use play_services_leaderboard_submit_score_with_tag to attach a tag to the submission.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_services_leaderboard_submit_score(leaderboard_id, score, callback)
Argument Type Description
leaderboard_id String The unique ID of the leaderboard.
score Real The raw score to submit.
callback Function The function to call once the submission completes.


Returns:

PlayServicesError

PlayServicesError.Ok if the request was accepted, PlayServicesError.NotAuthenticated or PlayServicesError.ActivityNull otherwise.


Triggers:

Callback

Fires once, when the submission completes or fails.

Key Type Description
status PlayServicesResult The submission's outcome.
report PlayServicesScoreReportInfo The per-time-span submission report. Only
present on success.

play_services_leaderboard_submit_score_with_tag

Submits a score to a leaderboard with an attached tag, same as play_services_leaderboard_submit_score but stamping score_tag onto the winning entry for later retrieval (e.g. to encode which game mode or character produced the score).

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_services_leaderboard_submit_score_with_tag(leaderboard_id, score, score_tag, callback)
Argument Type Description
leaderboard_id String The unique ID of the leaderboard.
score Real The raw score to submit.
score_tag String An arbitrary tag to associate with this score, up to 64 characters.
callback Function The function to call once the submission completes.


Returns:

PlayServicesError

PlayServicesError.Ok if the request was accepted, PlayServicesError.NotAuthenticated or PlayServicesError.ActivityNull otherwise.


Triggers:

Callback

Fires once, when the submission completes or fails.

Key Type Description
status PlayServicesResult The submission's outcome.
report PlayServicesScoreReportInfo The per-time-span submission report. Only
present on success.


Example:

play_services_leaderboard_submit_score_with_tag(leaderboard_id, 12345, "archer",
    function(_status, _report = undefined)
    {
        if (_status.success && _report.all_time.new_best)
            show_debug_message("New all-time best!");
    });

play_services_leaderboard_load_player_centered_scores

Loads the page of scores centered on the signed-in player's own rank. If the player has no score on this leaderboard, this loads the top page instead (same as play_services_leaderboard_load_top_scores).

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_services_leaderboard_load_player_centered_scores(leaderboard_id, span, leaderboard_collection, max_results, force_reload, callback)
Argument Type Description
leaderboard_id String The unique ID of the leaderboard.
span PlayServicesLeaderboardTimeSpan Which time span to load scores for.
leaderboard_collection PlayServicesLeaderboardCollection Which collection to load
scores for.
max_results Real The maximum number of scores to return, clamped to
[[macros](general.md#macros).PlayServicesMinPageSize, [macros](general.md#macros).PlayServicesMaxLeaderboardResults].
force_reload Boolean If true, bypasses the local cache and fetches fresh data from the
server.
callback Function The function to call once the load completes.


Returns:

PlayServicesError

PlayServicesError.Ok if the request was accepted, PlayServicesError.NotAuthenticated or PlayServicesError.ActivityNull otherwise.


Triggers:

Callback

Fires once, when the load completes or fails.

Key Type Description
status PlayServicesResult The load's outcome.
leaderboard PlayServicesLeaderboard The leaderboard's own metadata. Only present
on success.
scores Array of PlayServicesLeaderboardScore The loaded page of scores. Empty on
failure.

play_services_leaderboard_load_top_scores

Loads the top-ranked page of scores for a leaderboard.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_services_leaderboard_load_top_scores(leaderboard_id, span, leaderboard_collection, max_results, force_reload, callback)
Argument Type Description
leaderboard_id String The unique ID of the leaderboard.
span PlayServicesLeaderboardTimeSpan Which time span to load scores for.
leaderboard_collection PlayServicesLeaderboardCollection Which collection to load
scores for.
max_results Real The maximum number of scores to return, clamped to
[[macros](general.md#macros).PlayServicesMinPageSize, [macros](general.md#macros).PlayServicesMaxLeaderboardResults].
force_reload Boolean If true, bypasses the local cache and fetches fresh data from the
server.
callback Function The function to call once the load completes.


Returns:

PlayServicesError

PlayServicesError.Ok if the request was accepted, PlayServicesError.NotAuthenticated or PlayServicesError.ActivityNull otherwise.


Triggers:

Callback

Fires once, when the load completes or fails.

Key Type Description
status PlayServicesResult The load's outcome.
leaderboard PlayServicesLeaderboard The leaderboard's own metadata. Only present
on success.
scores Array of PlayServicesLeaderboardScore The loaded page of scores. Empty on
failure.


Example:

play_services_leaderboard_load_top_scores(leaderboard_id, PlayServicesLeaderboardTimeSpan.AllTime,
    PlayServicesLeaderboardCollection.Public, PlayServicesMaxLeaderboardResults, false,
    function(_status, _leaderboard = undefined, _scores = [])
    {
        if (!_status.success) return;

        for (var i = 0; i < array_length(_scores); i++)
            show_debug_message($"#{_scores[i].display_rank}: {_scores[i].display_score}");
    });

PlayServicesLeaderboardTimeSpan

The time span a leaderboard variant covers.

These constants are referenced by the following functions:

  • play_services_leaderboard_load_player_centered_scores
  • play_services_leaderboard_load_top_scores

These constants are referenced by the following structs:

  • PlayServicesLeaderboardVariant


Member Description
Daily Scores for the current day. Resets daily at 11:59 PM Pacific time.
Weekly Scores for the current week. Resets weekly, Sunday 11:59 PM Pacific time.
AllTime All scores ever submitted. Never resets.

PlayServicesLeaderboardScoreOrder

How raw scores are ranked on a leaderboard.

These constants are referenced by the following structs:

  • PlayServicesLeaderboard


Member Description
SmallerIsBetter A lower raw score ranks higher (e.g. a completion-time leaderboard).
LargerIsBetter A higher raw score ranks higher (e.g. a points leaderboard).

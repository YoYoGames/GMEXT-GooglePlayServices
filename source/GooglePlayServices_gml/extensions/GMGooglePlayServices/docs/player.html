play_services_player_current

Loads the currently signed-in player's own profile.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_services_player_current(callback)
Argument Type Description
callback Function The function to call once the load completes.


Returns:

PlayServicesError

PlayServicesError.Ok if the request was accepted, PlayServicesError.NotAuthenticated or PlayServicesError.ActivityNull otherwise.


Triggers:

Callback

Fires once, when the load completes or fails.

Key Type Description
status PlayServicesResult The load's outcome.
player PlayServicesPlayerInfo The current player's profile. Only present on
success.


Example:

play_services_player_current(function(_status, _player = undefined)
{
    if (_status.success)
        show_debug_message($"Signed in as {_player.display_name}");
});

play_services_player_stats_load

Loads aggregate play statistics for the currently signed-in player.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_services_player_stats_load(force_reload, callback)
Argument Type Description
force_reload Boolean If true, bypasses the local cache and fetches fresh data from the
server. Prefer false for most calls to benefit from caching.
callback Function The function to call once the load completes.


Returns:

PlayServicesError

PlayServicesError.Ok if the request was accepted, PlayServicesError.NotAuthenticated or PlayServicesError.ActivityNull otherwise.


Triggers:

Callback

Fires once, when the load completes or fails.

Key Type Description
status PlayServicesResult The load's outcome.
stats PlayServicesPlayerStatsInfo The player's stats. Only present on success.

play_services_player_load

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_services_player_load(player_id, force_reload, callback)
Argument Type Description

force_reload Boolean If true, bypasses the local cache and fetches fresh data from the

callback Function The function to call once the load completes.


Returns:

PlayServicesError

PlayServicesError.Ok if the request was accepted, PlayServicesError.NotAuthenticated or PlayServicesError.ActivityNull otherwise.


Triggers:

Callback

Fires once, when the load completes or fails.

Key Type Description
status PlayServicesResult The load's outcome.
player PlayServicesPlayerInfo The requested player's profile. Only present on
success.

PlayServicesPlayerInfo

A player's public Play Games Services profile. String fields are absent, not empty strings, when Google has no value for them - check presence before use.

This struct is referenced by the following functions:

  • play_services_player_current
  • play_services_player_load
  • play_services_friends_load
  • play_services_friends_load_more
  • play_services_friends_load_with_consent
  • play_services_player_search_show

This struct is referenced by the following structs:

  • PlayServicesLeaderboardScore


Member Type Description
player_id String The player's unique Play Games Services ID.
display_name String The player's display name.
title String The player's in-game title (e.g. an experience-level title), if any.
icon_image_uri String A URI for the player's icon-size profile image. Convert to a
local path with play_services_uri_to_path before loading it as a sprite.
hi_res_image_uri String A URI for the player's hi-res profile image. Convert to a local
path with play_services_uri_to_path before loading it as a sprite.

PlayServicesPlayerStatsInfo

Aggregate play statistics for a player, as estimated by Google Play Games Services. Any field can come back as -1 (Google's UNSET_VALUE) when there isn't enough data to calculate it - check for -1 before trusting a value.

Note

churn_probability, high_spender_probability, spend_probability, and total_spend_next_28_days mirror Google's own deprecated PlayerStats getters, which now always return -1 regardless of the player's real data - do not rely on these four for real predictions.

This struct is referenced by the following functions:

  • play_services_player_stats_load


Member Type Description
average_session_length Real The average session length, in minutes.
days_since_last_played Real The approximate number of days since the player last played.
number_of_purchases Real The approximate number of in-app purchases made by the player.
number_of_sessions Real The approximate number of sessions the player has had.
session_percentile Real The player's session-count percentile versus this game's player
base, 0-1 (higher means more sessions played).
spend_percentile Real The player's spend percentile versus this game's player base,
0-1 (higher means more spent).
churn_probability Real Always -1 - see the note above.
high_spender_probability Real Always -1 - see the note above.
spend_probability Real Always -1 - see the note above.
total_spend_next_28_days Real Always -1 - see the note above.

play_services_uri_to_path

Downloads and converts a Play Games image URI (as returned in icon_image_uri, hi_res_image_uri, cover_image_uri, etc. throughout this extension) into a local file path, suitable for loading with sprite_add. The image is fetched from the network if not already cached and written to a temporary PNG file.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_services_uri_to_path(uri, callback)
Argument Type Description
uri String The image URI to resolve, as returned by another function in this extension.
callback Function The function to call once the download/conversion completes.


Returns:

PlayServicesError

PlayServicesError.Ok if the request was accepted, PlayServicesError.ActivityNull otherwise.


Triggers:

Callback

Fires once, when the download completes, fails, or times out (after 30 seconds).

Key Type Description
status PlayServicesResult The conversion's outcome.
path String The local file path to the downloaded image. Only present on success.


Example:

play_services_uri_to_path(_player.icon_image_uri, function(_status, _path = undefined)
{
    if (_status.success)
        icon_sprite = sprite_add(_path, 1, false, false, 0, 0);
});

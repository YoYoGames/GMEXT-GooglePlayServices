Saved Games

Saving and loading player progress to Google's servers, synchronized across every device the player signs into, including conflict resolution and the system Saved Games UI.

play_services_saved_games_show_saved_games_ui

Shows the system Saved Games UI overlay, letting the player pick an existing slot, create a new one, or (optionally) delete a slot.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_services_saved_games_show_saved_games_ui(title, button_add, button_delete, max_results, callback)
Argument Type Description
title String The title text to display on the overlay.
button_add Boolean Whether to show a button for creating a new save slot.
button_delete Boolean Whether to show a button for deleting a save slot.
max_results Real The maximum number of existing save slots to list.
callback Function The function to call once the UI is dismissed.


Returns:

PlayServicesError

PlayServicesError.Ok if the UI was launched, PlayServicesError.NotAuthenticated or PlayServicesError.ActivityNull otherwise.


Triggers:

Callback

Fires once, when the overlay is dismissed - whichever way the player closed it.

Key Type Description
status PlayServicesResult The overlay's outcome. success is false only if
launching the picker itself failed (result is then PlayServicesSavedGamesUIResult.Error).
result PlayServicesSavedGamesUIResult Which way the overlay was closed.
metadata PlayServicesSnapshotMetadata The selected slot's metadata. Only present
when result is PlayServicesSavedGamesUIResult.Selected - open it with
play_services_saved_games_open using metadata.unique_name.


Example:

play_services_saved_games_show_saved_games_ui("Load or create a save", true, true, 5,
    function(_status, _result, _metadata = undefined)
    {
        if (_result == PlayServicesSavedGamesUIResult.Selected)
            play_services_saved_games_open(_metadata.unique_name, false,
                PlayServicesSavedGamesConflictPolicy.MostRecentlyModified, open_callback);
    });

play_services_saved_games_commit_and_close

Writes data to a save slot and closes it, releasing the handle opened by play_services_saved_games_open.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_services_saved_games_commit_and_close(options, callback)
Argument Type Description
options PlayServicesSavedGameCommitOptions The slot name, data, and metadata to
write. options.name must refer to a slot opened this session.
callback Function The function to call once the commit completes.


Returns:

PlayServicesError

PlayServicesError.Ok if the request was accepted, PlayServicesError.NotAuthenticated/PlayServicesError.ActivityNull, or PlayServicesError.InvalidArgument if options.name doesn't refer to a slot opened this session.


Triggers:

Callback

Fires once, when the commit completes or fails.

Key Type Description
status PlayServicesResult The commit's outcome.
metadata PlayServicesSnapshotMetadata The committed slot's server-confirmed
metadata. Only present on success.


Example:

var _options = new PlayServicesSavedGameCommitOptions();
_options.name = "slot_1";
_options.data = json_stringify(save_struct);
_options.desc = "Level 3, 00:12:34";
_options.played_time_millis = -1; // leave unchanged
_options.progress_value = -1;     // leave unchanged
_options.cover_image_path = "";   // leave unchanged

play_services_saved_games_commit_and_close(_options, function(_status, _metadata = undefined)
{
    if (_status.success)
        show_debug_message("Saved");
});

play_services_saved_games_load

Loads the metadata for every save slot belonging to the signed-in player.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_services_saved_games_load(force_reload, callback)
Argument Type Description
force_reload Boolean If true, bypasses the local cache and fetches fresh data from the
server.
callback Function The function to call once the load completes.


Returns:

PlayServicesError

PlayServicesError.Ok if the request was accepted, PlayServicesError.NotAuthenticated or PlayServicesError.ActivityNull otherwise.


Triggers:

Callback

Fires once, when the load completes or fails.

Key Type Description
status PlayServicesResult The load's outcome. success is true with an empty
snapshots array both for a genuinely empty account and for some documented offline edge cases in
Google's own API - if you need to tell "no saves" apart from "couldn't check", also verify
connectivity independently.
snapshots Array of PlayServicesSnapshotMetadata Every save slot's metadata. Empty on
failure or on a genuinely empty account.

play_services_saved_games_open

Opens a save slot by name, creating it first if requested. On success, the slot is held open until committed with play_services_saved_games_commit_and_close or dropped with play_services_saved_games_delete. Re-opening an already-open name safely replaces the held handle.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_services_saved_games_open(name, create_if_not_found, conflict_policy, callback)
Argument Type Description
name String The unique identifier of the save slot.
create_if_not_found Boolean If true, creates the slot when it doesn't already exist instead
of failing.
conflict_policy PlayServicesSavedGamesConflictPolicy How to resolve a conflict if
this slot has divergent local/server data. Only PlayServicesSavedGamesConflictPolicy.Manual
can ever produce an unresolved conflict in the callback - every other value auto-resolves on the
server, so pass Manual only when you're prepared to call
play_services_saved_games_resolve_conflict yourself.
callback Function The function to call once the open completes.


Returns:

PlayServicesError

PlayServicesError.Ok if the request was accepted, PlayServicesError.NotAuthenticated or PlayServicesError.ActivityNull otherwise.


Triggers:

Callback

Fires once, when the open completes or fails.

Key Type Description
status PlayServicesResult The open's outcome.
info PlayServicesSnapshotOpenInfo The opened slot, or the conflict to resolve.
Only present on success.


Example:

play_services_saved_games_open("slot_1", true, PlayServicesSavedGamesConflictPolicy.MostRecentlyModified,
    function(_status, _info = undefined)
    {
        if (!_status.success) return;

        if (_info.is_conflict)
        {
            // Only reachable when conflict_policy was Manual.
            play_services_saved_games_resolve_conflict(_info.conflict_id, true, resolve_callback);
        }
        else
        {
            var _save = _info.data != "" ? json_parse(_info.data) : undefined;
        }
    });

play_services_saved_games_resolve_conflict

Resolves a conflict previously reported by play_services_saved_games_open (with PlayServicesSavedGamesConflictPolicy.Manual) by picking one side as the winner.

Note

Resolving a conflict can itself produce a fresh conflict, per Google's own API - always check info.is_conflict on the result and be prepared to call this function again with the new conflict_id rather than assuming one call always settles it.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_services_saved_games_resolve_conflict(conflict_id, use_local, callback)
Argument Type Description
conflict_id String The conflict ID from the triggering
PlayServicesSnapshotOpenInfo.
use_local Boolean true to keep the local (device) side, false to keep the remote (server)
side.
callback Function The function to call once the resolution completes.


Returns:

PlayServicesError

PlayServicesError.Ok if the request was accepted, PlayServicesError.NotAuthenticated/PlayServicesError.ActivityNull, or PlayServicesError.InvalidArgument if there is no pending conflict matching use_local.


Triggers:

Callback

Fires once, when the resolution completes or fails.

Key Type Description
status PlayServicesResult The resolution's outcome.
info PlayServicesSnapshotOpenInfo The resolved slot, or a fresh conflict to
resolve again (see the note above). Only present on success.

PlayServicesSavedGamesConflictPolicy

How play_services_saved_games_open resolves a slot with divergent local/server data. Every value except Manual auto-resolves on the server without ever surfacing a conflict.

These constants are referenced by the following functions:

  • play_services_saved_games_open


Member Description
Manual The game resolves the conflict itself via
play_services_saved_games_resolve_conflict - the only value that can produce an
unresolved conflict result.
LongestPlaytime Keeps whichever side has the greater played_time_millis.
LastKnownGood Keeps the last version the server confirmed as consistent.
MostRecentlyModified Keeps whichever side has the more recent modification timestamp.
HighestProgress Keeps whichever side has the greater progress_value.

PlayServicesSavedGameCommitOptions

The metadata and content to write when committing a saved-game slot via play_services_saved_games_commit_and_close.

This struct is referenced by the following functions:

  • play_services_saved_games_commit_and_close


Member Type Description
name String The unique identifier of the save slot. Must match a slot already opened this
session with play_services_saved_games_open.
data String The save data to write, as a string (a JSON-encoded string is a common
choice for structured data).
desc String The description to display for this save slot in the system Saved Games UI.
Leave empty to keep the slot's existing description unchanged.
played_time_millis Real The total played time to record for this save, in milliseconds.
Pass a negative value to leave the slot's existing value unchanged.
progress_value Real The progress value to record for this save (an arbitrary,
developer-defined number used to compare saves, e.g. for conflict resolution heuristics). Pass a
negative value to leave the slot's existing value unchanged.
cover_image_path String A local file path to an image to use as the slot's cover image
(e.g. a screenshot saved via surface_save). Leave empty to keep the slot's existing cover image.

PlayServicesSnapshotOpenInfo

The result of opening a saved-game slot. Exactly one of two field groups is populated, selected by is_conflict: snapshot_metadata/data when the slot opened cleanly; conflict_id/ snapshot_metadata_local/data_local/snapshot_metadata_remote/data_remote when it opened into a conflict that needs play_services_saved_games_resolve_conflict. Only PlayServicesSavedGamesConflictPolicy.Manual can ever produce a conflict result - every other policy value makes Google Play auto-resolve on the server, so this struct's conflict fields only ever populate for callers using Manual.

This struct is referenced by the following functions:

  • play_services_saved_games_open
  • play_services_saved_games_resolve_conflict


Member Type Description
is_conflict Boolean Whether this open resulted in an unresolved conflict.
snapshot_metadata PlayServicesSnapshotMetadata The opened slot's metadata. Only
present when !is_conflict.
data String The opened slot's save data. Only present when !is_conflict.
conflict_id String The ID to pass to
play_services_saved_games_resolve_conflict. Only present when is_conflict.
snapshot_metadata_local PlayServicesSnapshotMetadata The local (device) side of
the conflict. Only present when is_conflict.
data_local String The local side's save data. Only present when is_conflict.
snapshot_metadata_remote PlayServicesSnapshotMetadata The remote (server) side of
the conflict. Only present when is_conflict.
data_remote String The remote side's save data. Only present when is_conflict.
